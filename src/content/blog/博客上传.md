文章放在：

`D:/_my_raspikvm/personal-site/src/content/blog`

新建一个 `.md` 文件，例如 `zotero-on-raspberry-pi.md`：

```
---
title: 在树莓派上部署 Zotero WebDAV
description: 使用树莓派保存 Zotero 附件并实现多端同步。
published: 2026-09-15
tags: [zotero, raspberry-pi]
draft: false
---

这里开始写正文。

## 配置方法

支持标准 Markdown、图片、代码块、表格和 LaTeX 公式。
```

然后在 `D:\_my_raspikvm\personal-site` 执行：

```
npm run build
git add src/content/blog
git commit -m "Publish Zotero WebDAV article"
git push origin main
```

推送后 GitHub Actions 会自动构建并发布到：

- 文章清单：[ljnxn.github.io/blog](https://ljnxn.github.io/blog/)
- 首页也会显示最新三篇文章。

注意：

- `draft: true`：保存到仓库但不公开。
- `draft: false`：正式公开。
- 文件名会成为文章网址，建议使用简短英文和连字符。
- 不要写入密码、Token、真实内网配置或未公开实验数据。
- 图片应放入 `public/`，文章中用 `/图片名.webp` 引用。
