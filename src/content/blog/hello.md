这个网站用来整理长期有效的工程记录，而不是堆放项目截图。

## 会公开什么

可以复现的实验过程、值得保留的技术判断，以及对其他人有帮助的工具和方法会放在公开博客。代码仍以 GitHub 仓库为准，文章负责解释代码背后的选择。

## 什么不会进入公开仓库

设备凭据、未发布研究材料、实验数据和内网结构细节不会进入公开仓库。私有工程只抽取经过检查、可独立理解的部分发布。

实验室入口与博客相互独立。入口通过 Tailscale Funnel 提供网络转发，并在服务端校验经过批准的 GitHub 身份；公开网页只负责申请和跳转，不能绕过认证。
